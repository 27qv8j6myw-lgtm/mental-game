# 앱 개인정보 보호 · 연령 등급 답안

App Store Connect → 멘탈게임 → **앱 개인정보 보호** 와 **앱 정보 → 연령 등급** 에 이렇게 답해요.
근거는 개인정보처리방침(`public/privacy.html`)과 실제 코드예요.

## 앱 개인정보 보호 (Privacy Nutrition Label)

**데이터 수집 여부**: 예, 데이터를 수집합니다.
**추적(Tracking)**: 모든 항목 **아니요**. 광고 식별자를 쓰지 않고, 다른 회사 앱·웹과 데이터를 엮지 않아요.

| 데이터 종류 (App Store 분류) | 무엇 | 사용 목적 | 사용자와 연결 | 추적 |
|---|---|---|---|---|
| 연락처 정보 → 이름 | 앱에서 쓰는 이름(실명), 로그인 계정의 이름 | 앱 기능 | 예 | 아니요 |
| 연락처 정보 → 이메일 주소 | 카카오·Google·Apple 로그인 때 제공에 동의한 이메일 | 앱 기능 | 예 | 아니요 |
| 금융 정보 → 기타 금융 정보 | 계좌이체 정산 때 직접 넣은 은행 이름·계좌번호 | 앱 기능 | 예 | 아니요 |
| 사용자 콘텐츠 → 사진 또는 비디오 | 로그인 계정의 프로필 사진(주소) | 앱 기능 | 예 | 아니요 |
| 사용자 콘텐츠 → 기타 사용자 콘텐츠 | 라운드 기록(골프장·날짜·홀별 스코어·상세 기록·정산 결과), 평균 타수·핸디캡 | 앱 기능 | 예 | 아니요 |
| 식별자 → 사용자 ID | 계정 식별자 | 앱 기능 | 예 | 아니요 |
| 기타 데이터 → 기타 데이터 유형 | 성별 (핸디캡·코스 레이팅 계산용) | 앱 기능 | 예 | 아니요 |

수집하지 않는 것: 위치, 연락처, 검색·방문 기록, 구매, 사용 데이터(분석), 진단(충돌 보고), 건강, 광고 데이터.

참고:
- 스코어카드 사진 읽기(사진을 Anthropic으로 보내 읽음)는 관리자만 쓰는 기능이에요. 일반 이용자에게 열면 '사용자 콘텐츠 → 사진 또는 비디오'의 목적에 그 내용을 함께 적어요.
- AI 기록 분석은 권한을 받은 사람만 써요. 홀별 기록만 보내고 이름은 보내지 않아요 (위 '기타 사용자 콘텐츠'에 들어가요).

## 연령 등급 설문

Apple의 새 연령 등급 설문(4+ · 9+ · 13+ · 16+ · 18+) 기준이에요.

| 항목 | 답 | 이유 |
|---|---|---|
| 자녀 보호 기능 · 연령 확인 | 없음 | |
| 제한 없는 웹 접근 | 아니요 | 앱 안에서 다른 사이트를 돌아다닐 수 없어요 (외부 링크는 Safari로 열어요) |
| 사용자 생성 콘텐츠 | 아니요 | 같은 라운드·랭킹에 이름·사진·스코어가 보이는 정도이고, 글·사진을 널리 올리는 기능은 없어요 |
| 메시지·채팅, 소셜 미디어, 광고 | 아니요 | |
| 성인·폭력·공포·약물 등 콘텐츠 | 모두 없음 | |
| 의료 · 건강 정보 | 없음 | |
| 경품·대회 (Contests) | **드물게** | 함께 친 사람끼리 월별 평균 타수 랭킹이 있어요 |
| 시뮬레이션 도박 | 없음 | |
| 도박 (실제 돈) | **아래 '결정할 것' 참고** | |
| 루트 박스 | 없음 | |

### 결정할 것: '도박' 항목

Apple은 도박을 '실제 돈을 걸고 하는 내기'로 정의해요. 멘탈게임은 돈을 받거나 보내지 않지만, 동반자끼리 정한 게임(타당·스킨스 등)의 금액을 계산하는 것이 핵심 기능이에요.

| 선택 | 결과 | 위험 |
|---|---|---|
| **있음으로 답하기 (권장)** | 연령 등급 18+ | 심사관이 앱 화면의 '내기' 문구를 봐도 등급과 어긋나지 않아요. 내기 기록·계산 앱과 같은 방식이라 허가증은 필요 없다고 심사 메모로 설명해요 |
| 없음으로 답하기 | 4+ 근처 | 심사관이 화면에서 '내기'를 보면 등급을 잘못 답했다고 거절할 수 있어요 |

연령 등급은 심사 뒤에도 바꿀 수 있지만, 처음부터 사실대로 답하는 쪽이 거절될 위험이 적어요.
